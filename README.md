# Placement Readiness Tracker

### Purpose

This project was developed as part of the **Industry Readiness Programme-II (CSE2596)** assignment.

The program helps track students' placement readiness by maintaining and analyzing scores in:

- Aptitude
- Verbal
- Coding

### Features

- Store student details and scores
- Add a new student
- Calculate average scores
- Assign grades based on performance
- Find the top scorer
- Identify students who need extra practice
- Solve the Runner-Up Score coding problem

### Files Included

- `placement_tracker.py` - Main Placement Readiness Tracker program
- `runner_up.py` - Runner-Up Score solution
- `README.md` - Project documentation
